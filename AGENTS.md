# Agent Instructions

## Mission
Implement repository work safely, incrementally, and in accordance with the repository's current code, documentation, tests, and GitHub issues.

## Working expectations
- Read the relevant repository docs and issue before changing code.
- Keep changes scoped to the requested work.
- Preserve standalone behavior unless the task explicitly changes it.
- Add or update tests for behavior changes.
- Run the repository's applicable quality gates before finishing.
- Record follow-up work as GitHub issues when appropriate rather than leaving hidden TODOs.
- Commit and push completed work unless the execution environment or user explicitly requires a different review flow.

## Sources of truth
Repository-local code, documentation, tests, and GitHub issues are authoritative for this repository. Do not depend on external Project Brain state, Daily Briefs, Beads, or machine-specific task-management files to determine project intent.
